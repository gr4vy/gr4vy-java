# RiskifiedAntiFraudOptionsShippingAddress

An additional shipping address to pass to the Riskified API.

Field names follow Riskified's Address model rather than the Gr4vy address
format, since these options are passed through to their API. The `country` sent
to Riskified is derived from `country_code`.
